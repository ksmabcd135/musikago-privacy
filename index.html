むしカゴ プライバシーポリシー

最終更新日: 2026年7月20日

「むしカゴ」(以下「本アプリ」)は、お子さまが安心して昆虫採集を楽しめるよう、 個人情報の収集を最小限に抑えて設計されています。本ポリシーでは、本アプリが どのような情報を扱うかをご説明します。

1. 写真について — 端末の外に出ません

  • 撮影した昆虫の写真は、すべてお使いの端末内にのみ保存されます。
  • 昆虫の判定(AI識別)は完全に端末内で処理され、写真が外部サーバーに送信されることは一切ありません。

2. 収集する情報

本アプリは、コレクションのバックアップのために以下の最小限の情報のみを扱います。

  • 匿名ID: アカウント登録は不要です。氏名・メールアドレス等は収集しません。Firebase 匿名認証によるランダムなIDのみを使用します。
  • おおよその位置(市区町村名のみ): 昆虫を見つけた場所の記録として、「都道府県+市区町村」の文字列のみを保存します。緯度・経度などの正確な位置情報は保存しません。位置情報の利用は任意で、許可しなくてもアプリは利用できます。
  • コレクションのメタデータ: 昆虫の種類・ニックネーム・捕まえた日時などのテキスト情報。写真そのものは含まれません。

3. 収集しない情報

  • 氏名、メールアドレス、電話番号、生年月日
  • 正確な位置情報(GPS座標)
  • 広告ID — 本アプリには広告がありません
  • 連絡先、通話履歴、他アプリの情報

4. 第三者への提供

収集した情報を第三者に販売・提供することはありません。データの保管には Google Firebase (Google LLC) を利用しており、Google のプライバシーポリシーが適用されます。

5. データの削除

アプリをアンインストールすると、端末内の写真とデータは削除されます。 サーバー上のバックアップデータの削除をご希望の場合は、下記の連絡先までお問い合わせください。

6. お子さまの保護者の方へ

本アプリは外部リンク・チャット・SNS機能・アプリ内購入・広告を含みません。 ご不明な点があれば、いつでもお問い合わせください。

무시카고 개인정보처리방침

최종 수정일: 2026년 7월 20일

'무시카고'(이하 '본 앱')는 어린이가 안심하고 곤충 채집을 즐길 수 있도록 개인정보 수집을 최소한으로 억제하여 설계되었습니다. 본 방침에서는 본 앱이 어떤 정보를 다루는지 설명합니다.

1. 사진 — 기기 밖으로 나가지 않습니다

  • 촬영한 곤충 사진은 모두 사용자의 기기 안에만 저장됩니다.
  • 곤충 판별(AI 식별)은 전부 기기 안에서 처리되며, 사진이 외부 서버로 전송되는 일은 일절 없습니다.

2. 수집하는 정보

본 앱은 컬렉션 백업을 위해 다음의 최소한의 정보만 다룹니다.

  • 익명 ID: 계정 가입이 필요 없습니다. 이름·이메일 등은 수집하지 않으며, Firebase 익명 인증의 무작위 ID만 사용합니다.
  • 대략적인 위치(시·군·구 이름만): 곤충을 발견한 장소 기록으로 "시/도 + 시·군·구" 문자열만 저장합니다. 위도·경도 등 정확한 위치 정보는 저장하지 않습니다. 위치 사용은 선택 사항이며 허용하지 않아도 앱을 사용할 수 있습니다.
  • 컬렉션 메타데이터: 곤충 종류·별명·잡은 날짜 등 텍스트 정보. 사진 자체는 포함되지 않습니다.

3. 수집하지 않는 정보

  • 이름, 이메일 주소, 전화번호, 생년월일
  • 정확한 위치 정보(GPS 좌표)
  • 광고 ID — 본 앱에는 광고가 없습니다
  • 연락처, 통화 기록, 다른 앱 정보

4. 제3자 제공

수집한 정보를 제3자에게 판매·제공하지 않습니다. 데이터 보관에는 Google Firebase(Google LLC)를 이용하며, Google의 개인정보처리방침이 적용됩니다.

5. 데이터 삭제

앱을 삭제하면 기기 안의 사진과 데이터가 삭제됩니다. 서버에 백업된 데이터의 삭제를 원하시면 아래 연락처로 문의해 주세요.

6. 보호자님께

본 앱은 외부 링크·채팅·SNS 기능·인앱 결제·광고를 포함하지 않습니다. 궁금한 점이 있으면 언제든 문의해 주세요.
