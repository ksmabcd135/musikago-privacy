むしカゴ プライバシーポリシー

最終更新日: 2026年9月15日

「むしカゴ」(以下「本アプリ」)は、お子さまが安心して昆虫採集を楽しめるよう、個人情報の収集を最小限に抑えて設計されています。本ポリシーでは、本アプリがどのような情報を扱うかをご説明します。

1. 写真について — 端末の外に出ません

  • 撮影した昆虫の写真は、すべてお使いの端末内にのみ保存されます。
  • 昆虫の判定(AI識別)は完全に端末内で処理され、写真が外部サーバーに送信されることは一切ありません。

2. 端末内で扱う情報

現在のリリース版はクラウド同期を有効にしておらず、次の情報も端末内にのみ保存します。

  • コレクションの情報: 昆虫の種類・ニックネーム・捕まえた日時・メモなどの情報。

クラウド同期を将来有効にする場合は、公開前に本ポリシーとストアのデータ開示を更新します。

3. 収集しない情報

  • 氏名、メールアドレス、電話番号、生年月日
  • 正確な位置情報(GPS座標)
  • おおよその位置情報および位置情報の権限
  • 広告ID — 本アプリには広告がありません
  • 連絡先、通話履歴、他アプリの情報

4. 第三者への提供

写真やコレクション情報を第三者に販売・提供・送信しません。

5. データの削除

アプリをアンインストールすると、端末内の写真とデータは削除されます。

6. お子さまの保護者の方へ

本アプリは外部リンク・チャット・SNS機能・アプリ内購入・広告を含みません。ご不明な点があれば、いつでもお問い合わせください。

무시카고 개인정보처리방침

최종 수정일: 2026년 9월 15일

'무시카고'(이하 '본 앱')은 어린이가 안심하고 곤충 채집을 즐길 수 있도록 개인정보 수집을 최소한으로 억제하여 설계되었습니다. 본 방침에서는 본 앱이 어떤 정보를 다루는지 설명합니다.

1. 사진 — 기기 밖으로 나가지 않습니다

  • 촬영한 곤충 사진은 모두 사용자의 기기 안에만 저장됩니다.
  • 곤충 판별(AI 식별)은 전부 기기 안에서 처리되며, 사진이 외부 서버로 전송되는 일은 일절 없습니다.

2. 기기 안에서 다루는 정보

현재 출시 빌드는 클라우드 동기화를 활성화하지 않으며, 다음 정보도 기기 안에만 저장합니다.

  • 컬렉션 정보: 곤충 종류·별명·잡은 날짜·메모 등의 정보.

향후 클라우드 동기화를 활성화한다면 공개 전에 본 방침과 스토어 데이터 공개 내용을 갱신합니다.

3. 수집하지 않는 정보

  • 이름, 이메일 주소, 전화번호, 생년월일
  • 정확한 위치 정보(GPS 좌표)
  • 대략적인 위치 정보 및 위치 권한
  • 광고 ID — 본 앱에는 광고가 없습니다
  • 연락처, 통화 기록, 다른 앱 정보

4. 제3자 제공

사진이나 컬렉션 정보를 제3자에게 판매·제공·전송하지 않습니다.

5. 데이터 삭제

앱을 삭제하면 기기 안의 사진과 데이터가 삭제됩니다.

6. 보호자님께

본 앱은 외부 링크·채팅·SNS 기능·인앱 결제·광고를 포함하지 않습니다. 궁금한 점이 있으면 언제든 문의해 주세요.
